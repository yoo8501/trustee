# 점검 시스템 고도화 - UI 화면 설계서

## 개요

수탁사 보안점검 시스템의 UX 흐름을 개선하고, 점검 결과 시각화 및 체크리스트 입력 UX를 고도화하기 위한 화면 설계서입니다.

---

## 현재 UX 분석 및 문제점

### 현재 UX 흐름
```
/inspections (메인 허브)
├── /inspections/templates        - 체크리스트 템플릿 목록
│   ├── /inspections/templates/new      - 템플릿 생성
│   └── /inspections/templates/[id]     - 템플릿 상세
└── /inspections/checklists       - 수탁사 체크리스트 목록
    ├── /inspections/checklists/new     - 체크리스트 생성
    └── /inspections/checklists/[id]    - 체크리스트 상세 (읽기 전용)
```

### 문제점 및 개선점

| 구분 | 현재 문제점 | 개선 방향 |
|------|------------|----------|
| 점검 메인 | 카드 2개만 있는 단순 허브 | 통계 요약, 최근 점검 현황 대시보드로 전환 |
| 체크리스트 목록 | 점수/등급 없음, 단순 상태만 | 점수, 등급 컬럼 추가 및 진행률 시각화 |
| 체크리스트 상세 | 결과 요약 없음, 차트 없음 | 점수 요약 패널, 카테고리별 시각화 추가 |
| 진행률 표시 | 없음 | 완료 항목 / 전체 항목 비율 표시 |
| 등급 시각화 | 없음 | 색상 기반 등급 배지 및 레이더 차트 |
| 답변 미흡 항목 | 따로 구분 없음 | "아니오" 답변 항목 하이라이트 |

## 화면 설계

### 1. 점검 메인 대시보드 (`/inspections`)

#### 레이아웃 와이어프레임

```
┌─────────────────────────────────────────────────────────────┐
│  점검 관리                                                   │
│  보안점검 체크리스트 현황을 확인하고 관리합니다.               │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  [StatCard] 총 체크리스트  [StatCard] 제출완료  [StatCard] 검토완료  [StatCard] 평균 점수 │
│      42개                      18개              12개           78점       │
│                                                             │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  최근 제출된 체크리스트                    [전체 보기 →]    │
│  ┌────────────────────────────────────────────────────┐    │
│  │  수탁사명       상태      점수   등급   제출일       │    │
│  │  ABC물류㈜     제출완료   82점   [B+]  2026-02-19  │    │
│  │  XYZ데이터     제출완료   65점   [C]   2026-02-18  │    │
│  │  DEF시스템     작성중     -      -     -           │    │
│  └────────────────────────────────────────────────────┘    │
│                                                             │
│  빠른 이동                                                  │
│  ┌──────────────────────┐  ┌──────────────────────┐        │
│  │ 📋 체크리스트 템플릿  │  │ ✅ 수탁사 체크리스트  │        │
│  │ 점검 기준 템플릿 관리 │  │ 수탁사별 점검 관리   │        │
│  └──────────────────────┘  └──────────────────────┘        │
└─────────────────────────────────────────────────────────────┘
```

#### 구성 요소
- **상단 StatCard 4개**: 총 체크리스트 수, 제출완료 수, 검토완료 수, 평균 점수
- **최근 제출 체크리스트**: 최근 5건의 요약 테이블 (DataTable 활용)
- **빠른 이동 카드**: 기존 카드 UI 유지

### 2. 점검 체크리스트 목록 (`/inspections/checklists`)

#### 레이아웃 와이어프레임

```
┌─────────────────────────────────────────────────────────────┐
│  수탁사 체크리스트                    [+ 체크리스트 생성]   │
│  수탁사에게 전달된 보안점검 체크리스트를 관리합니다.          │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  [상태 필터 ▾]  [기간 필터 ▾]  [수탁사 검색...]             │
│                                                             │
│  ┌──┬──────────┬────────┬──────────┬──────┬──────┬──────┐  │
│  │No│ 제목     │ 상태   │ 점수/등급│기한  │제출일│생성일│  │
│  ├──┼──────────┼────────┼──────────┼──────┼──────┼──────┤  │
│  │1 │ABC 2026  │[제출완료]│82점 [B+]│D-0  │2/19  │2/10  │  │
│  │2 │XYZ 보안  │[작성중]│ ████░ 40%│D-5  │ -    │2/15  │  │
│  │3 │DEF 점검  │[초안]  │    -     │D-10 │ -    │2/20  │  │
│  └──┴──────────┴────────┴──────────┴──────┴──────┴──────┘  │
│  총 23건                          [< 1 2 3 >]  행수 [10▾] │
└─────────────────────────────────────────────────────────────┘
```

#### 개선 사항
- **점수/등급 컬럼 추가**: 제출완료/검토완료 상태이면 점수 및 등급 표시
- **진행률 표시**: 작성중 상태이면 ProgressBar로 진행 비율 표시
- **수탁사 검색 필터**: 수탁사명으로 검색 가능
- **기간 필터 추가**: 생성일/제출일 기준 기간 필터

#### 등급 색상 정의

| 등급 | 점수 범위 | 색상 |
|------|---------|------|
| A+ | 95-100점 | `#27a644` (brand.green) |
| A | 90-94점 | `#4ea7fc` (brand.blue) |
| B+ | 80-89점 | `#00b8cc` (brand.teal) |
| B | 70-79점 | `#f0bf00` (brand.yellow) |
| C | 60-69점 | `#fc7840` (brand.orange) |
| D | 60점 미만 | `#eb5757` (brand.red) |

#### UX 상세 설계

**자동 저장**
- 각 항목 입력 시 500ms 디바운스 후 자동 저장
- 저장 상태: "저장 중...", "저장됨 ✓", "저장 실패 ✗" 표시
- 페이지 이탈 시 미저장 데이터 경고

**항목 상태 표시**
- 미답변: 기본 회색 테두리
- 적합(예): 초록색 왼쪽 보더
- 미흡(아니오): 주황색 왼쪽 보더 + ⚠ 아이콘
- N/A: 회색 배경, 흐린 텍스트

**진행률 계산**
- 답변 완료 항목(대상여부 미적용 포함) / 전체 항목
- 카테고리별 미니 프로그레스바 표시

**파일 첨부**
- 드래그앤드롭 지원
- 허용 형식: PDF, 이미지(PNG, JPG), 문서(DOC, DOCX, XLS, XLSX)
- 최대 10MB / 파일, 최대 5개 / 항목

**최종 제출**
- 미답변 항목이 있을 경우 경고 다이얼로그 표시
- 제출 후 수정 불가 안내
- 제출 완료 확인 페이지로 이동

## UX 흐름도

### 관리자 흐름

```
/inspections (대시보드)
│
├── 현황 파악
│   └── StatCard: 총 체크리스트, 제출완료, 검토완료, 평균점수
│
├── /inspections/checklists (목록)
│   ├── 필터링: 상태, 기간, 수탁사
│   └── 클릭 → 상세보기
│
└── /inspections/checklists/[id] (상세)
    ├── 점수/등급 확인 (ScorePanel)
    ├── 레이더 차트 확인
    ├── 미흡 항목 검토
    ├── 기한 변경
    ├── 토큰 재발급
    └── 검토 완료 처리
```

### 수탁사 담당자 흐름

```
이메일/링크 수신
│
└── /checklist/[token] (입력 화면)
    ├── 작성자 정보 입력 (최초 1회)
    ├── 카테고리별 항목 작성
    │   ├── 대상여부 선택
    │   ├── 답변 선택 (예/아니오/N/A)
    │   ├── 현황 입력
    │   ├── 파일 첨부
    │   └── 비고 입력
    ├── 자동저장 (실시간)
    └── 최종 제출 → 완료 페이지
```
