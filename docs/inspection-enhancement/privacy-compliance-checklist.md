# 개인정보보호법 기반 수탁사 점검 항목 체계서

## 1. 법적 근거

### 주요 관련 조항
| 조항 | 내용 | 점검 연관 |
|------|------|-----------|
| **개인정보보호법 제26조** | 업무위탁에 따른 개인정보의 처리 제한 | 위탁계약, 관리감독, 재위탁 제한 |
| **개인정보보호법 제29조** | 안전조치의무 | 기술적/관리적/물리적 보호조치 |
| **개인정보보호법 제31조** | 개인정보 보호책임자의 지정 | 보호책임자 지정 및 역할 |
| **개인정보보호법 제34조** | 개인정보 유출 통지 등 | 침해사고 대응 체계 |
| **시행령 제28조** | 업무위탁의 공개 | 위탁 내용 공개, 수탁자 교육 |
| **시행령 제30조** | 개인정보의 안전성 확보 조치 | 접근통제, 접근권한 관리, 암호화 등 |
| **개인정보의 안전성 확보조치 기준 (고시)** | 세부 기술적/관리적 보호조치 | 전 카테고리 |

### 위탁자(위탁사)의 관리감독 의무
개인정보보호법 제26조 제4항에 따라 위탁자는 수탁자가 개인정보를 안전하게 처리하는지 **정기적으로 교육 및 관리감독**을 실시해야 한다. 이를 위반할 경우 수탁자의 고의 또는 과실로 인한 손해배상 책임을 위탁자가 부담한다.

## 4. 데이터 모델 매핑

기존 시스템의 `ChecklistTemplate` 구조와의 매핑:

```
ChecklistTemplate (개인정보보호 수탁사 점검 v1.0)
├── ChecklistCategory (카테고리 1~7)
│   ├── no: 1~7
│   └── name: "개인정보 처리 현황", "관리적 보안 조치", ...
│
├── ChecklistSection (섹션 1.1, 1.2, ...)
│   ├── no: "1.1", "1.2", ...
│   └── name: "위탁 업무 범위 관리", "개인정보 현황 파악", ...
│
└── ChecklistItem (항목 1.1.1, 1.1.2, ...)
    ├── no: "1.1.1", "1.1.2", ...
    ├── question: "위탁계약서에 명시된 업무 범위 내에서만 ..."
    └── hint: "위탁계약서와 실제 처리 업무 비교 확인"
```

수탁사 응답 시 `TrusteeChecklistItem`:
- `answer`: "yes" | "no" | "not_applicable"
- `currentStatus`: 현재 이행 현황 서술
- `remarks`: 비고/개선 계획
- `evidenceFiles`: 증빙 자료 첨부
